# แอปบันทึกรายรับรายจ่าย

เว็บแอปสำหรับบันทึกรายรับรายจ่ายประจำวัน ใช้แทนไฟล์ Excel `OwnLife Personal Financial Planner`
ออกแบบให้ใช้บน iPhone เป็นหลัก โดยเพิ่มลงหน้าจอโฮมแล้วเปิดเหมือนแอปทั่วไป

เขียนด้วย HTML / CSS / JavaScript ล้วน ไม่มี framework ไม่ต้อง build
กราฟวาดด้วย SVG ในโค้ดเอง จึงใช้งานได้แม้ไม่มีเน็ต

## สิ่งที่ต่างจากไฟล์ Excel เดิม

| เรื่องที่เคยติดขัด | ในแอปนี้ |
|---|---|
| ต้องสร้างไฟล์ใหม่ทุกปี | ใช้ได้ทุกปีในแอปเดียว เปลี่ยนปีได้ที่หน้า **ปี** |
| ต้องกรอกตารางประเภทใหม่ทุกเดือน | ประเภทเป็นชุดกลางชุดเดียว ใช้ร่วมกันทุกเดือนทุกปี |
| ช่อง *กลุ่มรายการ* เป็นสูตร แก้ผิดช่องแล้วพัง | แอปเติมกลุ่มให้เองจากประเภทที่เลือก |
| ต้องลงวันที่ในเดือนของชีตนั้นเท่านั้น | ใส่วันที่ไหนก็ได้ รายการจะไปอยู่ในเดือนที่ถูกต้องเอง |
| เผลอลบสูตรหรือกราฟแล้วพัง | ไม่มีสูตรให้พัง กราฟคำนวณใหม่ทุกครั้งที่เปิด |
| ต้องก๊อปไฟล์สำรองเอง | มีปุ่มส่งออกไฟล์สำรอง และเตือนเมื่อไม่ได้สำรองนานเกิน 14 วัน |

## วิธีเปิดใช้งาน

### 1. นำขึ้นโฮสต์

ไฟล์เว็บอยู่ที่รากของ repo นี้ พร้อมเสิร์ฟได้ทันที

**GitHub Pages** (repo นี้ตั้งไว้ให้ใช้วิธีนี้)

1. ไปที่ Settings → Pages
2. Source เลือก **Deploy from a branch** → branch `main` → folder `/ (root)`
3. รอสักครู่ แล้วเปิด `https://natthaphat-math.github.io/expense-income-tracking/`
   ด้วย Safari บน iPhone

**Firebase Hosting**

```bash
npm install -g firebase-tools
firebase login
firebase init hosting     # ตอบ public directory ว่า . (จุด)
firebase deploy
```

> ต้องเปิดผ่าน `https://` หรือ `localhost` เท่านั้น service worker จึงจะทำงาน
> (เปิดไฟล์ตรง ๆ ด้วย `file://` แอปยังใช้ได้ แต่จะไม่มีโหมดออฟไลน์)

**ลองบนเครื่องตัวเอง**

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

### 2. เพิ่มลงหน้าจอโฮม (iPhone / iPad)

1. เปิดเว็บด้วย **Safari** (แอปอื่นเพิ่มลงหน้าจอโฮมไม่ได้)
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
3. เลือก **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
4. เปิดจากไอคอนบนหน้าจอโฮม จะได้เต็มจอไม่มีแถบ Safari

### 3. นำข้อมูลเดิมเข้าแอป

> **สำคัญ** iOS แยกที่เก็บข้อมูลของแอปบนหน้าจอโฮม ออกจาก Safari ปกติคนละที่
> ถ้านำเข้าข้อมูลใน Safari แล้วไปเปิดจากไอคอนบนหน้าจอโฮม จะไม่เห็นข้อมูล
> **ให้เปิดจากไอคอนบนหน้าจอโฮมก่อน แล้วค่อยนำเข้าที่นั่น**

1. แปลงไฟล์ Excel เป็น JSON (ดูหัวข้อถัดไป) จะได้ไฟล์ `data/import-2026.json`
2. ส่งไฟล์เข้า iPhone — แอร์ดรอป, ส่งเข้าแชตตัวเอง หรือวางไว้ใน iCloud Drive
3. เปิดแอปจากไอคอนบนหน้าจอโฮม → **ตั้งค่า** (มุมขวาบน) → **เลือกไฟล์ JSON**
4. แอปจะแสดงจำนวนรายการที่พบให้ตรวจก่อน แล้วเลือก
   - **แทนที่ทั้งหมด** — ใช้อันนี้ตอนตั้งค่าครั้งแรก จะได้ประเภทและงบชุดของคุณเอง
     แทนที่ประเภทตัวอย่างที่ติดมากับแอป
   - **รวมข้อมูล** — ใช้ตอนกู้ข้อมูลทีหลัง เก็บของเดิมไว้และเพิ่มของใหม่เข้าไป
     (รายการซ้ำใช้ฉบับที่ใหม่กว่า นำเข้าไฟล์เดิมซ้ำจะไม่เกิดรายการซ้ำ)

### 4. สำรองข้อมูล

ข้อมูลทั้งหมดเก็บอยู่ใน **เครื่องนี้เครื่องเดียว** ยังไม่มีการซิงก์ขึ้นคลาวด์
ถ้าลบแอปออกจากหน้าจอโฮม ข้อมูลจะหายไปด้วย จึงควรสำรองเป็นระยะ

ไปที่ **ตั้งค่า** → **ส่งออกไฟล์สำรอง** จะได้ไฟล์ `tracker-backup-YYYY-MM-DD.json`
บน iPhone จะขึ้นแผ่นแชร์ให้เลือกเซฟลงไฟล์ของฉัน หรือส่งเข้าแชตตัวเองก็ได้
ถ้าไม่ได้สำรองเกิน 14 วัน แอปจะขึ้นแถบเตือนที่หน้าหลัก

## วิธีใช้

**หน้าหลัก** — วันที่วันนี้ ยอดรวมรายรับ/รายจ่ายของวันนี้ และรายการทั้งหมดของวันนี้
แตะที่รายการใดก็ได้เพื่อแก้ไขหรือลบ

**ปุ่มล่างจอ** — `ปี` ซ้ายล่าง, `รับ` / `จ่าย` ตรงกลาง, `เดือน` ขวาล่าง

**บันทึกรายการ** — พิมพ์หรือพูดสั้น ๆ แล้วแอปจะแยกให้เอง

```
ก๋วยเตี๋ยว 20 บาท อาหาร    →  ชื่อ: ก๋วยเตี๋ยว   มูลค่า: 20   ประเภท: ค่าอาหาร
ก๋วยเตี๋ยว 20 อาหาร         →  ได้ผลเหมือนกัน
ก๋วยเตี๋ยว20บาท             →  พิมพ์ติดกันก็ได้ (เสียงพูดมักออกมาแบบนี้)
กาแฟ ๘๕ บาท                →  เลขไทยก็ได้
ก๋วยเตี๋ยว                  →  ใส่แค่ชื่อ แล้วค่อยกรอกที่เหลือทีหลัง
```

กรอกแค่ **รายละเอียด** อย่างเดียวก็บันทึกได้ ช่องอื่นเว้นไว้ได้หมด
ถ้าเคยบันทึกชื่อนี้มาก่อน แอปจะเดาประเภทให้จากครั้งล่าสุด

**บันทึกหลายรายการพร้อมกัน** — ขึ้นบรรทัดใหม่ แอปจะเปลี่ยนเป็นการ์ดให้ตรวจทีละรายการ

```
ก๋วยเตี๋ยว 20 บาท อาหาร
ชานม 45 น้ำหวาน
รถเมล์ 25 เดินทาง
```

**หน้าเดือน** — กราฟวงกลมแยกตามประเภท (สลับดู รายจ่าย / รายรับ / การออม),
ยอดรวมของเดือน, รายการแยกตามวันพร้อมยอดรวมรายวัน,
และส่วนที่พับเก็บได้: งบประมาณเทียบใช้จริง, รายได้, การออม, กราฟยอดคงเหลือรายวัน

**หน้าปี** — สรุปทั้งปี กราฟแท่งเทียบรายรับ/รายจ่าย 12 เดือน (แตะแท่งเพื่อเปิดเดือนนั้น)
และความคืบหน้าเทียบเป้าหมายทั้งปี

## แปลงไฟล์ Excel เป็น JSON

```bash
pip install openpyxl
python3 tools/convert_xlsx.py /path/to/planner.xlsx \
    --out data/import-2026.json \
    --report data/import-report.md
```

ได้ไฟล์ออกมาสองไฟล์

- `data/import-2026.json` — ไฟล์สำหรับนำเข้าแอป
- `data/import-report.md` — รายงานการแปลง: จำนวนรายการต่อเดือน, แถวที่ข้ามและเหตุผล,
  และตารางเทียบยอดที่คำนวณได้กับยอดในชีต

> ⚠️ **repo นี้เป็นสาธารณะ** `data/`, `*.xlsx` และ `*backup*.json` อยู่ใน `.gitignore` แล้ว
> ห้ามเอาออกและห้าม `git add -f` ไฟล์พวกนี้เด็ดขาด
>
> GitHub Pages เสิร์ฟ **ทุกไฟล์** ในโฟลเดอร์ที่เผยแพร่ ไม่ใช่เฉพาะไฟล์ที่ลิงก์ถึง
> ถ้าไฟล์สำรองหลุดขึ้นมา ประวัติการเงินทั้งหมดจะกลายเป็น URL ที่ใครก็โหลดได้
> และลบทีหลังก็ไม่ช่วย เพราะยังค้างอยู่ใน git history และใน cache ของ Google
>
> ตัวโค้ดในนี้ไม่มีข้อมูลส่วนตัว ประเภทตั้งต้นเป็นชุดกลาง ๆ และไม่ได้ตั้งงบมาให้
> ข้อมูลจริงอยู่ในเครื่องของผู้ใช้เท่านั้น ไม่ได้ถูกอัปโหลดไปไหน

## ชั้นเก็บข้อมูล

`js/storage.js` กำหนด interface ไว้ชุดเดียว หน้าจอทุกหน้าคุยผ่าน `store.js` เท่านั้น
ไม่มีหน้าไหนแตะที่เก็บข้อมูลตรง ๆ

```js
getAll()            // Promise<Transaction[]>
put(tx)             // Promise<Transaction>
putMany(txs)        // Promise<Transaction[]>
delete(id)          // ลบแบบนุ่ม (deleted = true)
getSettings()       // Promise<Settings>
saveSettings(s)     // Promise<Settings>
```

ตอนนี้ใช้ `LocalStorageAdapter` เก็บลง `localStorage` ของเครื่อง
ทุกรายการมี `id`, `updatedAt` และ `deleted` ไว้พร้อมสำหรับการซิงก์ในอนาคต

### การซิงก์ข้ามเครื่อง

`FirestoreAdapter` มีเมธอดชุดเดียวกับ `LocalStorageAdapter` และถูกใช้ผ่าน
`SyncManager` ซึ่งทำงานแบบ **เครื่องมาก่อน**: บันทึกลง localStorage ทันที
แล้วส่งขึ้น Firestore เบื้องหลัง ถ้าไม่มีเน็ตหรือโหลด Firebase ไม่ได้
แอปก็ทำงานได้ครบทุกอย่างเหมือนเดิม

ที่อยู่ข้อมูล: `users/{uid}/transactions/{id}` และ `users/{uid}/meta/settings`
เข้าสู่ระบบด้วยลิงก์ทางอีเมล ไม่มีรหัสผ่าน

เปิดใช้ที่ **ตั้งค่า → ซิงก์ข้อมูล → เข้าสู่ระบบด้วยอีเมล**

> **บน iPhone ต้องคัดลอกลิงก์มาวาง ไม่ใช่กดลิงก์**
> การกดลิงก์ในอีเมลจะเปิดใน Safari ซึ่งแยกที่เก็บข้อมูลกับแอปบนหน้าจอโฮม
> ให้กดค้างที่ลิงก์ → คัดลอก → กลับมาวางในช่องที่แอปเตรียมไว้
> การเข้าสู่ระบบจะได้เกิดขึ้นในแอปที่มีข้อมูลจริง

ขั้นตอนตั้งค่าใน Firebase Console ทั้งหมดอยู่ใน
[`docs/firebase-setup.md`](docs/firebase-setup.md)

กำลังจะทำเป็นแอป iOS (EZ Expense) — สิ่งที่ต้องรู้ก่อนเริ่มเขียนใหม่อยู่ใน
[`docs/ios-handover.md`](docs/ios-handover.md)

สรุปสิ่งที่ห้ามลืม

- จำกัดสิทธิ์ใน **Firestore Security Rules** ไม่ใช่แค่ในโค้ดฝั่งเว็บ
  (กฎที่เตรียมไว้อยู่ใน [`docs/firestore.rules`](docs/firestore.rules))
  และห้ามใช้กฎแบบ test mode เด็ดขาด — repo นี้เป็นสาธารณะ ใครก็อ่าน config ได้
- จำกัด Firebase Web API key ใน Google Cloud Console — ผูก HTTP referrer
  ไว้กับโดเมนที่โฮสต์จริง และเปิดเฉพาะ API ที่จำเป็น
- ใส่เฉพาะโดเมนที่โฮสต์จริงใน Authorized domains ของ Firebase Auth
